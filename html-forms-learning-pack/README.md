# HTML Forms for User Input — Fresher Learning Pack

This pack covers:
- Role of forms in web pages
- Form elements
- Single-line text field
- Text area
- Checkbox
- Radio buttons
- Password field
- Pull-down menu
- File selector

Open `index.html` in VS Code and use Live Server.

Note: These examples demonstrate HTML form structure and controls. A real application needs a backend/server to process submitted data.
