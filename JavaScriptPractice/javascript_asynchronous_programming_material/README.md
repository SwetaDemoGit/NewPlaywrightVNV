# JavaScript Asynchronous Programming

This package contains presentation-ready theory and topic-wise JavaScript examples.

## Files

- `theory.md` — detailed theory
- `01` to `14` — source code examples

## Recommended Order

Callbacks → Promises → Promise Chaining → Async/Await → Error Handling → Event Loop → Non-blocking I/O → Promise.all() → Best Practices

## Run

With Node.js installed:

```text
node 01-synchronous-vs-asynchronous.js
```

Replace the filename as required.
