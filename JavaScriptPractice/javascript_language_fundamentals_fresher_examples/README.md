# JavaScript Language Fundamentals - Fresher Practice

This ZIP contains simple JavaScript examples for:

1. Keywords, Reserved Words and Identifiers
2. Data Types
3. Variables: let, const and var
4. Operators and Assignments
5. if / else / else if
6. switch
7. Loops
8. Functions
9. Arrow Functions
10. Best Practices
11. Practice Exercises

## Prerequisite

Install Node.js before running the examples.

Check installation:

    node --version

## How to Run

Open the terminal in this folder and run any file:

    node 01_keywords_identifiers.js

For example:

    node 04_operators_assignments.js

You can run each file independently.

## Suggested Teaching Order

Start with files 01 through 04.

Then teach flow control using files 05 through 07.

Then teach functions using files 08 and 09.

Finish with best practices and exercises using files 10 and 11.

## Note

The examples intentionally use only the language fundamentals covered in this lesson. They avoid advanced JavaScript topics so learners can focus on the core concepts.
