# JavaScript Objects and Arrays - Fresher Practice

This ZIP contains source code for:

1. Introduction to Objects
2. Creating and Using Objects
3. Object Properties and Methods
4. Arrays and Common Array Methods
5. Iterating Over Arrays
   - for
   - forEach
   - map
   - filter
6. Objects and Arrays Together
7. Prototypes
8. Constructor Functions and Prototypes
9. Inheritance using Classes
10. Useful Object Methods
11. Best Practices
12. Practice Exercises

## Prerequisite

Node.js should be installed.

Check:

    node --version

## Running an Example

Open a terminal in this folder and run:

    node 01_objects_basics.js

Examples can be run independently.

## Suggested Teaching Order

Start with:

    01_objects_basics.js
    02_objects_methods_nested.js

Then teach arrays:

    03_arrays_basics.js
    04_array_methods.js

Then iteration:

    05_array_iteration.js
    06_map_filter.js
    07_objects_arrays_together.js

Then introduce object-oriented concepts:

    08_prototypes.js
    09_constructor_prototype.js
    10_inheritance_classes.js

Finish with:

    11_object_methods.js
    12_best_practices.js
    13_practice_exercises.js

## Teaching Note

The examples are intentionally focused on the requested Objects and Arrays topics.
They use only concepts needed to demonstrate these topics and avoid unrelated advanced JavaScript APIs.
