# JavaScript Testing - Beginner Demos

Topics covered:
1. Introduction to testing frameworks
2. Mocha setup and running tests
3. Writing unit tests
4. Testing asynchronous code
5. Mocking and stubbing
6. Testing best practices

## Setup

Run:

npm install

Then run all Mocha tests:

npm test

You can also run:

npx mocha

The examples use CommonJS (`require`) to keep the setup simple.
