# Regular Expressions in JavaScript

This folder contains JavaScript examples corresponding to the theory in `theory.md`.

## Files

- `theory.md` - detailed theory and examples
- `01-introduction.js` - introduction to Regex
- `02-basic-syntax.js` - basic syntax, character classes, quantifiers, anchors, and flags
- `03-regexp-object.js` - RegExp object, constructor, test(), and exec()
- `04-string-methods.js` - match(), search(), and replace()
- `05-validation.js` - basic validation examples
- `06-best-practices.js` - practical best practices
- `07-complete-example.js` - combined validation example

## Running the examples

Make sure Node.js is installed.

Run an individual file:

```bash
node 01-introduction.js
```

or:

```bash
node 05-validation.js
```

You can also open the `.js` files in a browser environment and run them from the developer console.
