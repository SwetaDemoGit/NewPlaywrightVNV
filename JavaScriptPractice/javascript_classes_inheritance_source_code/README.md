# JavaScript Classes and Inheritance

This folder contains simple examples for freshers.

## Files

1. `01_introduction_to_classes.js`
   - Class
   - Object
   - Creating multiple objects
   - Methods

2. `02_constructors_and_methods.js`
   - Constructor
   - `this`
   - Methods
   - Initializing object properties

3. `03_inheritance_extends.js`
   - Inheritance
   - `extends`
   - Parent/child relationship

4. `04_superclass_subclass_super.js`
   - Superclass
   - Subclass
   - `super()`
   - Calling parent constructor

5. `05_getters_and_setters.js`
   - Getter
   - Setter
   - Property validation

6. `06_best_practices.js`
   - Focused classes
   - Meaningful names
   - Appropriate inheritance
   - Reusing common functionality

7. `07_complete_example.js`
   - Combines all major concepts in one example

## How to run

Using Node.js:

```bash
node 01_introduction_to_classes.js
```

You can run each `.js` file separately.

## Quick revision

- Class = blueprint for creating objects
- Object = instance of a class
- Constructor = runs automatically when an object is created
- Method = function inside a class
- `extends` = creates inheritance
- Superclass = parent class
- Subclass = child class
- `super()` = calls the parent constructor
- Getter = reads a value
- Setter = changes/validates a value
