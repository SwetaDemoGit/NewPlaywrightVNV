# Introduction to XML - Learning Pack

Topics covered:
- Evolution of XML
- Role of XML in Web Applications
- Different members of the XML family
- Introduction to XML Namespace

## Suggested order

1. Read theory.md
2. Open each numbered XML example
3. Compare the XML structure with the explanation
4. Open `07-complete-demo.xml` for the combined example

All examples are plain XML and can be opened in VS Code.
