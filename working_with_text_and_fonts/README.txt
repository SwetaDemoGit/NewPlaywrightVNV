Working with Text and Fonts

Files:
- index.html   -> Working example
- style.css    -> CSS used by the example
- theory.md    -> Crisp theory with detailed examples and explanations

How to run:
1. Extract the ZIP.
2. Open index.html in any modern browser.
3. Open theory.md in VS Code or any Markdown editor.
4. Modify style.css and refresh index.html to observe changes.
