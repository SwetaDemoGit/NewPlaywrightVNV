# HTML Frames Learning Pack

Topics covered:
- Need for frames
- Traditional `<frameset>` and `<frame>`
- Column and row frames
- Nested frames
- Named frames and target navigation
- Modern `<iframe>` alternative

Important: `<frameset>` and `<frame>` are obsolete in HTML5 and are included here for legacy understanding. `<iframe>` is still supported for embedding content.

Open `index.html` in VS Code and run with Live Server.
