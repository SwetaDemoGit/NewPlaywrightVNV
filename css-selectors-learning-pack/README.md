# CSS Selectors - Learning Pack

This pack covers:
- Type Selector
- Universal Selector
- ID Selector
- Class Selector
- Combined example

## How to use

1. Open this folder in VS Code.
2. Open `index.html`.
3. Use Live Server or open the HTML file in a browser.
4. Open each demo to see the selector in action.

The `theory.md` is written in a learner-friendly format:
Concept -> Example -> Code Explanation -> Demo.
