# TypeScript — Object Destructuring

## Run the examples

Compile a TypeScript file:
```bash
npx tsc src/01-basic-destructuring.ts
```

Run the generated JavaScript:
```bash
node src/01-basic-destructuring.js
```

You can also use:
```bash
tsc src/01-basic-destructuring.ts
```
