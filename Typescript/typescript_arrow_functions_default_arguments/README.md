# TypeScript — Arrow Functions & Default Arguments

## Run the examples

1. Open this folder in VS Code.
2. Open Terminal.
3. Install TypeScript if required:

```bash
npm install -g typescript
```

4. Compile a TypeScript file:

```bash
tsc src/01-arrow-basic.ts
```

5. Run the generated JavaScript:

```bash
node src/01-arrow-basic.js
```

## Recommended project setup

```bash
npm init -y
npm install typescript --save-dev
npx tsc src/01-arrow-basic.ts
node src/01-arrow-basic.js
```
