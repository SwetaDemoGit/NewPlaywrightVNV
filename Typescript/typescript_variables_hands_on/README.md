# TypeScript Variables — var, let and const

Source code for the TypeScript variables topic.

## Files

- `01-basic-variables.ts` — basic typed variables
- `02-type-safety.ts` — type checking
- `03-const.ts` — const and reassignment
- `04-type-inference.ts` — type inference
- `05-let-vs-const.ts` — choosing let vs const
- `06-var.ts` — var in TypeScript
- `07-shopping-cart.ts` — real-world example
- `08-hands-on.ts` — practice exercise

## Run

Install TypeScript if needed:

```bash
npm install -g typescript
```

Check the TypeScript version:

```bash
tsc --version
```

Compile a file:

```bash
tsc src/01-basic-variables.ts
```

This creates:

```text
src/01-basic-variables.js
```

Run the generated JavaScript:

```bash
node src/01-basic-variables.js
```

You can also compile and run any of the other `.ts` files in the same way.
