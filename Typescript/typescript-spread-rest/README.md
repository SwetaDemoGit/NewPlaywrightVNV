# TypeScript - Spread and Rest Operators

Beginner-friendly examples and hands-on exercises.

## Topics Covered

- Spread Operator with Arrays
- Combining Arrays
- Adding Values to Arrays
- Copying Arrays
- Spread Operator with Objects
- Adding Object Properties
- Updating Object Properties
- Rest Operator with Functions
- Rest Operator for Calculating Totals
- Rest with a Normal Parameter

## How to Run

### 1. Install TypeScript (if needed)

```bash
npm install -g typescript
```

### 2. Compile the TypeScript file

```bash
tsc src/spread-rest.ts
```

This creates `src/spread-rest.js`.

### 3. Run the JavaScript file

```bash
node src/spread-rest.js
```

## Hands-On Exercises

1. Combine two arrays using Spread.
2. Add values before and after an existing array using Spread.
3. Copy an array using Spread and modify only the copy.
4. Add a property to an object using Spread.
5. Create a new object with an updated property using Spread.
6. Create `calculateTotal(...numbers)` using Rest.
7. Create `introduce(name, ...hobbies)` using Rest.
