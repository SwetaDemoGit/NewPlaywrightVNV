# TypeScript Interfaces - Source Code

This folder contains simple examples covering TypeScript interfaces.

## Topics

1. Basic interface
2. Interface with methods
3. Methods with parameters
4. Optional properties
5. Readonly properties
6. Class implementing an interface
7. Interface inheritance
8. Multiple interfaces
9. Interface + polymorphism
10. Interface and type

## Run the examples

Make sure TypeScript is installed:

    npm install -g typescript

Compile a file:

    tsc 01-basic-interface.ts

Run the generated JavaScript:

    node 01-basic-interface.js

You can repeat the same process for each `.ts` file.

## Important

JavaScript does not have a built-in `interface` keyword.
Interfaces are a TypeScript feature.
