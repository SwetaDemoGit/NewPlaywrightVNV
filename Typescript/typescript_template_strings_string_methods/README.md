# TypeScript — Template Strings & String Methods

## Run an example

Compile:
```bash
npx tsc src/01-template-strings.ts
```

Run:
```bash
node src/01-template-strings.js
```

You can also compile a specific file with:
```bash
tsc src/01-template-strings.ts
```
